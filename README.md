# SisVendas
Projeto de sistema de vendas simples feito em C# para o evento de "Imerção em programação" da Fatec Jundiaí.

# Projeto da atividade de “Imersão em Programação: C#”
Com ele você é capaz de cadastrar clientes, mercadorias e realizar pedidos.
Através de alguns cliques essas tarefas podem ser executadas, e mais tarde, se precisar, pode ser gerado a lista de todos os clientes, mercadorias ou pedidos que estão cadastradas no sistema.
Ao criar pedidos, o valor total do pedido é mostrado dinamicamente ao valor cadastrado para a mercadoria informada.
Caso algum tipo de erro ocorra, são mostradas mensagens explicativas ao usuário para explicar o ocorrido.
Lembrando que neste projeto não estou usando nenhum banco de dados, portando ao encerrar a aplicação, os dados são perdidos.
